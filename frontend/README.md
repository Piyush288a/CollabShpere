# CollabSphere — Frontend

## Overview
This directory contains the React.js frontend application created with Vite, React Router DOM, and Tailwind CSS.

## Planned Frontend Structure (`frontend/`)

> *Note: Subdirectories inside `src/` will be introduced incrementally during Phase 10 (Frontend Integration) and are not created during Phase 0.*

| Directory | Responsibility |
| :--- | :--- |
| `src/components/` | Reusable UI components |
| `src/pages/` | Route-level pages |
| `src/services/` | Backend API communication |
| `src/hooks/` | Reusable React hooks |
| `src/context/` | Shared application state when required |
| `src/assets/` | Frontend assets |

```text
frontend/
└── README.md            # Frontend overview guide
```

## Setup Instructions (Future Phase)
1. Run `npm install` once Vite/React setup is initialized in Phase 10.
2. Run `npm run dev` to start Vite frontend development server.
